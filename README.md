# Promille

A blood alcohol tracker for the phone. Open `index.html` in Safari and use
Share → Add to Home Screen to run it full screen like an app.

- Set a session start time and log beer, wine, spirits, cocktails and more
- Live estimate (Widmark formula with gradual absorption and hourly burn-off)
- Curve with forecast, time under the legal limit and time back to zero
- Warns before the peak takes you over your own warning line
- "If you keep drinking" forecast for 1 to 5 more of a chosen drink
- Five food settings, from empty stomach to a heavy meal
- One-tap water logging, with a reminder after two drinks without water
- Eight levels with effects and warnings
- Everything is stored on the device only

The value is an estimate. Never use it to decide whether you can drive.
